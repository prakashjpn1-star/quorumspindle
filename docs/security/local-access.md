# Local access and lab boundaries

Bind API and lab listeners to loopback, validate Host/Origin and enforce fictional operator roles. Disposable runtime-only session values stay out of URLs, logs and Git. Peer/worker messages validate cluster/job identity and expected term/epoch/fence.

Allowlisted lab controls operate only on directories/processes created by the harness. Fault injection is disabled in normal mode and uses a separate local capability. Payloads, nesting, queues, pages, report sizes and active protocol work have finite configured caps. Reject scripts, arbitrary SQL, paths and remote targets.

Browser text is escaped and keyboard operation covers every action. Dataset deletion clearly names the isolated test target and requires confirmation in the runtime. The system uses generated data; it makes no production authentication or hostile-code sandbox claim.
